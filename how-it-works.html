How It Works

From request to record, in five clear steps

Here's what happens after a pickup request is submitted, for both the customer waiting on a pickup and the admin coordinating it.

    Two roles, one smooth process

    As a Customer

    • Log in and submit a pickup request
    • Choose waste type and an available date
    • Track the status of your request
    • View collection results and history

    As an Admin

    • Review and approve incoming requests
    • Manage pickup schedules
    • Record collected waste type and weight
    • Monitor data and generate reports
